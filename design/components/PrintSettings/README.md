# PrintSettings

The sidebar controls, mapped one-to-one to the printer's options: Paper (`a4` | `letter` | `continuous`), Density 1–8 (default 5), Dithering, Copies, and Fit (`page` | `width`, for photos).

- Density is an 8-step bar: steps below the value filled `ink`, the value in `heat`. Labels "Lighter"/"Darker" under it.
- Dithering uses plain words: Auto (= hybrid/threshold/Atkinson by file type), Sharp (threshold), Photo (Atkinson or Floyd), Ordered. Show the mapping in a caption.
- Changing a setting re-renders the payout; don't ask for confirmation.
- Advanced options (threshold, gamma, margins, font size) go behind an "Advanced" disclosure, not on the main panel.
